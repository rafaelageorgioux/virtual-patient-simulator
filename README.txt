32 CASES VIRTUAL PATIENT SIMULATOR — HISTORY COMPOSER FIX

This build changes the history entry area to a larger, high-contrast question box.

Fixes:
- dark visible text while typing
- visible cursor
- visible placeholder text
- white background
- clearer purple focus border
- larger question composer instead of the old chat-style input

HOW TO RUN
1. Move the WHOLE 32cases_project folder to your Desktop.
2. Open Terminal.
3. Type:
   cd ~/Desktop/32cases_project
4. Then:
   streamlit run 32cases.py

All 32 cases and all 34 visual files are preserved.
